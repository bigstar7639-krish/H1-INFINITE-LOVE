# Blender Build Guide - Aira H1 - Step by Step (Easy Tamil + English)

## Step 1: Blender open pannu
New File > General

## Step 2: Body
- Add Cube > Scale pannu > Body shape ku sculpt pannu
- OR: Use free base mesh, but MODIFY fully to Aira H1 proportions - do NOT use copyrighted character base

## Step 3: Head + Face
- Sphere add pannu > Oval shape ku scale pannu
- Eyes: 2 spheres, Violet-Blue gradient material
- Mouth: Small box, lip-sync ku separate

## Step 4: Hair - H1 Twin-Flow
- Cap: Head mela oru cap mesh
- Bangs: Left side longer
- Twin-tails: 2 long tubes, waist varaikum

## Step 5: Outfit
- Hoodie: White, loose
- Skirt: Navy, pleated - Cylinder + pleats
- Shoes: White sneakers

## Step 6: Rig
- Add Armature > Humanoid
- 55 bones per skeleton.json
- Weight paint: Automatic Weights, aprom manual fix

## Step 7: Blendshapes
- Shape Keys add pannu - 32 names from blendshapes.json
- Oru onna sculpt pannu, test pannu

## Step 8: Export
- VRM: VRM Add-on > Export
- GLB: File > Export > glTF 2.0

Phone la Blender illa na, PC la pannu, file ah phone ku anuppu.
