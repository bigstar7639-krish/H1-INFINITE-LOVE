# Vision Spec - Phase 10

## Features (7)
1. Camera - User taps, indicator on, photo local only
2. Image Understanding - Describe photo in Tamil+English
3. Object Detection - Person, cat, dog, car, book, etc.
4. OCR - Tamil + English + Hindi text from photo
5. Scene Understanding - Bedroom / Garden / Outside?
6. Visual Q&A - "Itha photo la enna irukku?"
7. Screen Understanding - Screenshot user shares, with permission only

## Privacy - MUST
- Camera / Screen only with permission + indicator
- Photo stays on phone, upload only if user taps Share
- No background capture
- No face recognition of other people without consent

## What is NOT done
- No camera running yet
- No ML model file yet - on-device model in Phase 13
