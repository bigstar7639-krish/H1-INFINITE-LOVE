# H1 INFINITE LOVE - Privacy Policy (Simple)

- Un data un phone la thaan irukku.
- Password / OTP / Bank engayum save panna maatom.
- Camera / Mic - ne tap pannina mattum.
- Contacts / Calendar - ne permission kudutha mattum, upload panna maatom.
- Ne eppo venalum: View / Edit / Delete / Delete ALL / Export pannalam.
- Memory off pannina, naan onnum nyabagam vechikka maaten.
- Cloud ku auto upload illa.
