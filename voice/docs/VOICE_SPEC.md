# Voice Spec - Phase 07

## Aira H1 Voice
- Female, young adult, warm, clear
- Tamil + English mix default
- Pitch 1.05, Speed 1.0 base
- Controls: Pitch 0.7-1.4, Speed 0.7-1.4

## Features
- Speech Recognition (Android STT first)
- Text-to-Speech (Android TTS first)
- Real-time conversation
- Voice interruption - user speaks, Aira stops
- Emotion-based voice - 19 emotions -> pitch/speed
- Lip-sync - visemes A-E-I-O-U-M
- Voice speed + pitch controls in Settings
- Wake-word: "Hey Aira" where supported, else Tap-to-Talk

## Privacy
- Mic indicator MUST show when mic is on (Phase 16)
- Mic only when user taps Talk or enables wake-word
- No background recording

## What is NOT done
- No real voice model file yet
- No cloud TTS key yet
